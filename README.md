## 📌 Overview  
QuickMed is a web-based healthcare application designed to assist users during emergencies by providing:

- Fast access to essential medicines  
- Real-time hospital bed availability  
- Simple and intuitive user flow for quick decision-making  

The project was developed as part of an **AI-assisted Software Development Lifecycle (SDLC)** assignment.

---

## 🎯 Problem Statement  
In emergency situations, users often face delays in:
- Finding available medicines  
- Locating hospitals with vacant beds  
- Making quick and informed decisions  

QuickMed aims to reduce these delays by offering a **centralized digital solution**.

---

## 🚀 Features  

- 🔍 Medicine search functionality  
- 🧾 Prescription upload (conceptual)  
- 🚚 Emergency medicine ordering (simulated)  
- 🏥 Hospital search based on location  
- 🛏️ Real-time bed availability (ICU, oxygen, general)  
- ✅ Bed booking simulation  
- 🔔 Order & booking confirmation  
- 📍 Simple and user-friendly interface  

---

## 🧱 Tech Stack  

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Basic simulation (JavaScript / simple logic)  
- **Platform:** Replit / Lovable (AI-assisted development)  

---

## 🧪 How to Run the Project  

1. Open the application link  
2. Start from the home screen  
3. Choose:
   - Order Medicine  
   - Find Hospital  
4. Follow the flow:
   - Search → Select → Confirm  
5. View confirmation and tracking
